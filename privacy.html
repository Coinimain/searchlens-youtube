PRIVACY POLICY

SearchLens for YouTube

Last updated: August 2026

Overview

SearchLens for YouTube is a browser extension that adds advanced search controls to YouTube search-result pages. SearchLens is available for supported browsers including Google Chrome, Mozilla Firefox, and Microsoft Edge.

This Privacy Policy applies to the supported browser versions of SearchLens and explains what information the extension accesses, how that information is used, and what may be stored when you use SearchLens.

Information SearchLens processes

To provide its search filtering, sorting, and cleanup features, SearchLens reads information that is already displayed on YouTube search-result pages. Depending on the feature being used, this may include:

  • Video titles
  • Channel names
  • Video duration information
  • Visible view counts
  • Video links and YouTube video identifiers
  • Visible search-result metadata

This information is used to apply the filters, sorting options, cleanup controls, and search features selected by the user.

User activity and clicked videos

SearchLens can detect when you click a YouTube video link from a YouTube search-results page. This is used for the optional feature that can hide watched or previously clicked videos.

When this functionality is used, SearchLens may store the associated YouTube video identifier locally using the browser's extension storage so the extension can recognize that video later.

SearchLens does not record the contents of videos you watch, your viewing duration, comments, messages, account credentials, or activity outside the functionality described in this policy.

Web history

For the optional watched or previously clicked video filtering feature, SearchLens may locally remember identifiers for YouTube videos that you clicked from search-result pages.

This information is used only to help SearchLens recognize and hide previously clicked videos when that option is enabled.

Information stored by the extension

SearchLens uses the browser's local extension storage to remember settings and preferences so they can persist between browser sessions. Stored information may include:

  • Selected SearchLens filter settings
  • Date-range preferences
  • Search-result cleanup preferences
  • Display behavior preferences
  • Panel and launcher state
  • Floating launcher position and visibility
  • First-run interface state
  • Locally remembered YouTube video identifiers for the optional previously clicked video feature

The exact technical storage mechanism may vary slightly between supported browsers, but this information remains associated with the locally installed SearchLens extension.

Local processing and data transmission

SearchLens processes the YouTube search-result information required for its features within the user's browser.

SearchLens does not send extension settings, SearchLens filter data, locally remembered video identifiers, or the YouTube page information it processes to a developer-operated server.

SearchLens does not require a SearchLens account and does not sell user data.

How information is used

Information accessed or stored by SearchLens is used only to provide the extension's search-enhancement functionality, including:

  • Filtering YouTube search results
  • Sorting currently loaded search results
  • Applying keyword, title, channel, duration, and view-count filters
  • Applying custom date-range searches
  • Hiding selected result types and page elements
  • Remembering user preferences and display behavior
  • Supporting the optional previously clicked video filter

SearchLens does not use this information for advertising, creditworthiness, lending decisions, data brokerage, or purposes unrelated to the extension's search functionality.

Permissions and YouTube access

SearchLens requires access to YouTube pages so it can add the SearchLens interface, read visible search-result information needed for user-selected filters, detect navigation within YouTube, and apply filtering, sorting, and cleanup options to search results.

SearchLens also uses the browser's extension storage permission or equivalent extension storage capability to save settings, interface preferences, and locally remembered information required for its features.

SearchLens does not use its YouTube page access for purposes unrelated to its search-enhancement functionality.

Data sharing and transfer

SearchLens does not sell user data or transfer the information it handles to third parties for advertising, marketing, data brokerage, creditworthiness, lending, or unrelated purposes.

Information processed locally by SearchLens is not transmitted to a developer-operated analytics or data-collection service.

Third-party services and external links

SearchLens may provide optional links to third-party websites or services, including Ko-fi and the relevant browser extension store, such as the Chrome Web Store, Firefox Add-ons, or Microsoft Edge Add-ons.

These links open only when selected by the user. Third-party websites and extension stores operate under their own terms and privacy policies. SearchLens does not control their data practices.

Browser-specific versions

SearchLens may have separate packages for Google Chrome, Mozilla Firefox, Microsoft Edge, and other supported browsers. Minor technical differences may exist between browser versions to accommodate each browser's extension platform.

Unless a browser-specific version states otherwise, the information-handling practices described in this Privacy Policy apply across supported versions of SearchLens.

Changes to this policy

This Privacy Policy may be updated if SearchLens features, permissions, supported browsers, or data-handling practices change. The latest version will be published on this page.

Contact and support

For questions about SearchLens or this Privacy Policy, use the support contact provided on the relevant browser extension store listing or visit the SearchLens support page.
